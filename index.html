Export lên GitHub Gist (tuỳ chọn)

Cần GitHub token của chính bạn với quyền gist — không được lưu trong source, chỉ giữ trong bộ nhớ tab này trong phiên làm việc. Gọi thẳng GitHub API từ trình duyệt (endpoint Gist hỗ trợ CORS nên không cần backend). Không dùng token có quyền rộng hơn mức cần thiết.

Chạy hoàn toàn client-side — mã nguồn Lua của bạn không được gửi lên server nào (trừ khi bạn chủ động bấm "Xuất lên Gist").
Xem trong trang chủ của cgcommand trong project để biết kiến trúc pipeline, giới hạn tương thích Lua 5.1–5.4, và cách chạy test suite.

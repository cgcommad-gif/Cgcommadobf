Lexer → Parser → AST → Custom Bytecode → Stack-based VM → Protected Lua Output — 100% client-side
Đọc trước khi dùng: Đây là công cụ tự viết (không dùng thư viện Lua obfuscation ngoài). Bộ lexer/parser/compiler/VM đã được kiểm chứng bằng 18+ test case chạy qua một VM tham chiếu viết bằng JS (vì môi trường build này không có Lua interpreter để chạy thật). Bản thân file vm.js — chương trình Lua sẽ thực thi output — là bản port thủ công từ VM tham chiếu đó, được review kỹ nhưng chưa được chạy trên Lua interpreter thật. Hãy tự chạy thử script đã bảo vệ (đặc biệt mức Strong) trước khi dùng cho việc quan trọng. Xem README để biết đầy đủ giới hạn (goto phức tạp, thuộc tính <const>/<close> của 5.4, toán tử bitwise chỉ chạy trên Lua 5.3+...).
